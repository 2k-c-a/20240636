# 로컬 시연 순서

## 시작 전

- README에 따라 backend에서 Uvicorn을 127.0.0.1:8000으로 실행한다. 학습 시연에는 Supabase가 필요 없다.
- 회원·게시판을 시연하려면 본인 개발 프로젝트·프로필·실제 이메일 테스트 계정을 준비한다. 토큰·키·비밀번호와 메일 링크를 발표 화면에 표시하지 않는다.
- 최신 검증 상태는 TEST_RESULTS.md를 확인한다. 계정 A/B·현재 CSP의 Auth/지도·실기기 검증은 완료로 주장하지 않는다.

## 1. 학습 시연

1. 홈에서 시각화를 열고 준비된 예제 실행 기록이라는 안내를 설명한다. 사용자 코드를 실제 실행하는 서비스는 아니다.
2. BFS 기본 예제를 다음 버튼으로 진행하며 한국어 설명·강조 코드·큐·발견한 노드·현재 노드를 함께 보여 준다.
3. 같은 단계에서 Python→C++→Java→Kotlin→Rust→C→JavaScript를 전환하고 단계·그래프 상태가 유지되는지 보여 준다.
4. 재생·일시정지, 0.5/1/2배, 단계 슬라이더·이전·처음으로를 사용한다. 이전은 저장된 스냅샷 복원이다.
5. DFS의 호출 스택, 이분 탐색의 찾지 못함/빈 배열, 버블 정렬의 역순/중복 예제를 선택한다. 예제 변경은 0단계에서 시작한다.
6. 360px·768px·PC에서 레이아웃을 확인한다. 한 모바일 화면에 코드·그래프 전체가 동시에 들어오는 것은 필수 조건이 아니며 내부/세로 스크롤로 확인한다.

## 2. 회원·게시판 시연 (실제 연동 확인 후)

1. 사이트에서 테스트 이메일·비밀번호·닉네임으로 가입한다. 이용자가 Supabase 서비스에 가입할 필요는 없다.
2. 같은 브라우저에서 확인 메일 링크를 열고 로그인·프로필 생성을 확인한다. 닉네임이 없으면 프로필 보완 화면에서 정한다.
3. 게시판에서 시연용 제목에 `[시연]`을 붙인 글을 작성하고 목록·필터·더 보기·상세를 보여 준다.
4. 본인 글을 수정하고 version/ETag에 따른 변경을 확인한다. 다른 사용자에게 편집 버튼이 보이지 않는지 별도 브라우저에서 확인한다.
5. 두 화면에서 같은 글을 열고 한쪽을 먼저 저장한 뒤 다른 쪽에서 충돌을 재현한다. 최신 내용과 초안을 비교하고 덮어쓰기 여부를 판단한다.
6. 본인의 테스트 글을 삭제한다. 비밀번호 재설정은 본인 테스트 계정으로만 실행하고 메일 링크·새 비밀번호는 공유하지 않는다.

## 실패 시

- 회원 기능 미설정·연결 장애이면 학습 시연을 계속하고 실제 연동 미검증을 알린다. 성공으로 꾸미지 않는다.
- 메일이 오지 않으면 발송 조건·제한과 스팸함을 확인한다. 반복 발송으로 제한을 소모하지 않는다.
- 쓰기 요청이 응답 없이 끝나면 목록을 먼저 확인한다. 자동으로 같은 글을 재전송하지 않는다.
- 401은 같은 페이지에서 재로그인, 412는 최신 글 비교, 404는 삭제된 글 안내를 따른다. 초안을 복사하기 전 새로고침하지 않는다.
- 지도 타일이 보이지 않으면 장소 설명·외부 지도 링크를 사용하고, 임베드 정상 확인으로 기록하지 않는다.

## 정리

- 시연 중 본인이 만든 테스트 글만 UI에서 확인한 뒤 삭제한다. 다른 글·기존 사용자·DB 테이블을 일괄 삭제하지 않는다.
- 선택 실행 통합 테스트는 생성한 글 UUID를 정리한다. 프로필·Auth 테스트 계정은 자동 삭제 대상이 아니므로 개발자가 보유 여부를 결정한다.
- 로그아웃하고 임시 브라우저 탭을 닫는다. 터미널의 Ctrl+C로 서버를 종료한다.
- commit/push는 별도 사용자 요청 때만 한다. .env·.venv·토큰·메일 링크를 Git에 포함하지 않는다.


## 추가 학습 시연

BFS에서 격자 미로를 골라 벽·거리·최단 경로를 설명한다. 유니온 파인드는 합치기 전후 부모 표와 경로 반감을, 다익스트라는 거리 갱신과 배열 기반 O(V²)를, 배낭 DP는 이전 행의 두 선택을, 위상 정렬은 진입 차수·큐와 사이클 예제를, 투 포인터는 오른쪽/왼쪽 경계와 누적합을 보여 준다. 복잡도 패널의 설명을 펼쳐 코드 구현에 따른 전제를 설명한다. 현재 총 36예제이며 모든 유형을 길게 시연하기보다 발표 시간에 맞춰 대표 2~3개를 고른다.
