알고리즘 실행 과정을 눈으로 확인하는 학습 사이트

알고리즘 코드를 한 단계씩 따라가며, 그 단계가 자료구조의 상태를 어떻게 바꾸는지 한국어 설명과 함께 보여주는 학습용 웹사이트를 만들고 있습니다. BFS·격자 미로, DFS, 이분 탐색, 버블 정렬, 유니온 파인드, 다익스트라, 배낭 DP, 위상 정렬, 투 포인터를 Python, C++, Java, Kotlin, Rust, C, JavaScript 코드로 살펴볼 수 있습니다. 준비한 예제의 실행 기록을 재생하는 방식이며, 입력한 코드를 실제로 실행하는 기능은 아닙니다.

개발 중입니다. 9개 알고리즘의 36개 예제를 한 단계씩 따라가며 언어를 전환하고 시간복잡도·공간복잡도와 구현 전제를 확인할 수 있습니다. 회원가입·로그인과 질문 게시판을 사용할 수 있습니다.
