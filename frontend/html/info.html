사이트 소개

이 사이트는 모바일 웹 수업의 프로젝트로, 알고리즘의 실행 과정을 코드와 자료구조의 상태로 함께 보여주는 학습용 웹사이트입니다. 알고리즘을 처음 배우는 학생이 "이 줄이 실행되어 상태가 이렇게 바뀌었다"를 화면만 보고 설명할 수 있게 하는 것이 목표입니다.

현재 상태: 개발 중입니다. 9개 알고리즘의 36개 예제를 Python·C++·Java·Kotlin·Rust·C·JavaScript 코드로 볼 수 있고, 회원가입·로그인과 질문 게시판을 사용할 수 있습니다. 시각화는 준비한 예제의 실행 기록을 재생하는 방식이며 사용자가 입력한 코드를 실행하지 않습니다.

소스 코드는 GitHub 프로필 (새 창에서 열림)에서 볼 수 있습니다. 학교 위치는 지도 페이지에서 확인할 수 있습니다.

페이지 구성표

현재 만들어진 페이지 목록
번호 파일 페이지 주요 내용
1 index.html 홈 사이트 목적과 현재 상태, 페이지 안내, 외부 링크
2 visualizer.html 시각화 BFS·격자 응용·DFS·탐색·정렬·유니온 파인드·최단 경로·배낭 DP·위상 정렬·투 포인터와 복잡도 학습
3 info.html 소개 사이트 소개, 구성표
4 idea.html 아이디어 프로젝트 기획서
5 map.html 지도 장안대학교 지도, 장소 검색
6 gallery.html 갤러리 이미지, 비디오 자리 (수업 실습)
7 contact.html 문의 문의 양식 (수업 실습, 전송 기능 없음)
8 login.html 로그인 로그인 (회원가입 signup.html, 비밀번호 재설정 reset-password.html, 내 정보 profile.html, 메일 링크 확인 auth-callback.html과 이어짐)
9 board.html 게시판 질문 목록·글쓰기 (글 보기·수정·삭제는 post.html)
공통 스타일: style.css · 공통 스크립트: site.js · 시각화 전용: visualizer.css, visualizer.js · 회원 화면 전용: auth.css, auth-pages.js · 게시판 전용: board.css, board.js, post.js
