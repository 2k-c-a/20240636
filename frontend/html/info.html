ABOUT THIS SPACE

작은 단계를 따라, 깊게 이해하기

알고리즘 실행 시각화는 코드의 실행 순서와 자료구조의 변화를 함께 살펴보는 학습 공간입니다.

이렇게 학습해 보세요

  1. 알고리즘과 예제를 선택하세요.

    9개 알고리즘과 36개 예제에서 기본 동작과 경계 상황을 비교할 수 있습니다.

  2. 다음 단계로 진행하며 변화를 살펴보세요.

    강조된 코드 줄, 한국어 설명, 자료구조를 함께 보세요. 이전 단계로 돌아가거나 자동 재생할 수 있습니다.

  3. 언어를 바꿔 같은 구현을 비교하세요.

    Python · C++ · Java · Kotlin · Rust · C · JavaScript를 지원합니다. 언어를 바꿔도 현재 단계가 유지됩니다.

  4. 풀리지 않은 질문은 나누세요.

    게시판에서 질문을 읽고, 로그인 후 글과 댓글을 남길 수 있습니다.

학습 화면은 준비된 예제의 실행 기록을 재생합니다. 사용자가 입력한 코드를 실행하지 않습니다.
